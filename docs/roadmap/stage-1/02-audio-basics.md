# 02 · 音频基础

> 📍 阶段一 · 知识整理 02 ｜ 核心技能：能现场估算任何参数组合的音频裸流码率与体积

## 声音是什么

声音是空气压力的连续波动。麦克风把它转换成连续变化的电压——**模拟信号**。但计算机存不了「连续」，只能存「一个一个的数」，于是需要两步数字化：**采样**（在时间上取点）与**量化**（把每个点的幅度变成整数）。

## 采样：每秒取多少个点

- **采样率（Hz）**：每秒对声波取点的次数。
- **奈奎斯特采样定理**：要完整还原频率上限为 f 的信号，采样率必须 ≥ 2f。
- 人耳听觉上限约 20kHz → 理论上 40kHz 就够，所以 CD 用 44.1kHz。

| 场景 | 采样率 | 说明 |
| --- | --- | --- |
| 电话 | 8 kHz | 语音频带仅 300~3400Hz，够用且极省带宽 |
| 语音识别 | 16 kHz | 覆盖人声主要能量 |
| 音乐 CD | 44.1 kHz | 历史标准 |
| 影视 / 现代 RTC | 48 kHz | 视频工业统一标准，通话主流选择 |

> 记忆点：**采样率决定「能听到多高的频率」**。电话音质闷，就是因为 8kHz 只保留了 4kHz 以下的频率。

## 量化：每个点多精细

- **位深（bit depth）**：每个采样点的振幅用多少 bit 表示。常见 16bit（CD、通用）、24bit（专业录音）。
- 经验规律：**每增加 1bit，动态范围约增加 6dB**。16bit ≈ 96dB 动态范围，已覆盖「安静房间到摇滚现场」。
- 量化误差听感上是底噪；位深越高底噪越低。

## 声道

- 单声道（mono）：一路数据，人声场景足够。
- 立体声（stereo）：左右两路，码率翻倍。
- 5.1 / 7.1 环绕：影视与家庭影院。
- **RTC 通话几乎都是单声道**：省一半带宽，人声不受损。

## 码率与体积：必须会算

未压缩 PCM 的码率公式：

```
码率 = 采样率 × 位深 × 声道数
```

典型组合：

| 场景 | 组合 | 码率 |
| --- | --- | --- |
| 电话 | 8kHz × 16bit × 1 | 128 kbps |
| RTC 通话 | 48kHz × 16bit × 1 | 768 kbps |
| CD 音乐 | 44.1kHz × 16bit × 2 | ≈ 1411 kbps |
| 影视制作 | 48kHz × 24bit × 2 | 2304 kbps |

一分钟体积 = 码率 ÷ 8 × 60：

- RTC 通话裸流：768 ÷ 8 × 60 ≈ **5.8 MB/分钟**
- 48kHz × 16bit × 双声道：1536 ÷ 8 × 60 ≈ **11.5 MB/分钟**（概览页自测题的答案）

对比：AAC 128kbps 的听感已接近 CD——**压缩了 10 倍以上**，这就是编码器存在的意义（编码原理不在本站范围）。

## PCM：数字音频的「裸流」

- PCM（Pulse Code Modulation）= 采样 + 量化之后的原始数据，**零压缩**。
- WAV 文件 ≈ PCM + 一个简单文件头，大得理所当然。
- 链路位置：麦克风采集出来的第一手数据就是 PCM → 交给音频编码器（Opus / AAC）压缩 → 才进入封装与传输。
- 阶段三会看到：WebRTC 中 `getUserMedia` 拿到的音频，最终也是以压缩帧（Opus）在 RTP 里传输。

## 关键要点

- 采样率决定频率上限（奈奎斯特），位深决定精度（+6dB/bit），声道数翻倍码率翻倍。
- 码率 = 采样率 × 位深 × 声道数；体积 = 码率 ÷ 8 × 时长。这两个公式要形成肌肉记忆。
- PCM 是一切音频处理与编码的起点。
