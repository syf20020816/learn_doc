# 阶段一：音视频基础概念与理论

> ⏱️ **学习时间**：3 周（每天 1~2 小时，约 30 学时） · 累计周期：第 1~3 周

> 📚 **本阶段知识整理已就绪**，建议按顺序学习：
> [01 数字化全流程](/roadmap/stage-1/01-digital-pipeline) · [02 音频基础](/roadmap/stage-1/02-audio-basics) · [03 视频基础](/roadmap/stage-1/03-video-basics) · [04 封装与容器](/roadmap/stage-1/04-containers) · [05 业务形态与时延谱系](/roadmap/stage-1/05-latency-spectrum) · [06 核心指标](/roadmap/stage-1/06-metrics)

## 阶段目标

用三周建立音视频的全景认知：搞清楚一段音视频从真实世界到屏幕与音箱的完整旅程，掌握音频 / 视频的核心参数，分清编码格式与封装格式，建立「时延谱系」的心智模型。本阶段为后续所有协议学习打底。

## 知识点清单

### 数字化全流程

- [ ] 理解完整链路：采集 → 采样/量化 → 编码（概念层）→ 封装 → 传输 → 解封装 → 解码（概念层）→ 渲染
- [ ] 分清「编码格式（codec）」与「封装格式（container）」的区别
- [ ] 理解为什么本站不深学编解码：协议与架构层面的学习不依赖编解码算法细节

### 音频基础

- [ ] 采样率（44.1kHz / 48kHz）与奈奎斯特采样定理（概念即可）
- [ ] 位深（bit depth）、声道数、比特率
- [ ] PCM 是什么；会估算一段裸音频的体积（如 48kHz / 16bit / 双声道 / 60s ≈ 11 MB）
- [ ] 常见场景的音频参数：通话（48kHz / 16bit / 单声道 ≈ 768 kbps）、音乐（44.1kHz / 16bit / 立体声）

### 视频基础

- [ ] 分辨率、宽高比、帧率（24 / 30 / 60fps）
- [ ] 色彩空间：RGB 与 YUV，为什么视频偏爱 YUV，YUV420 省在哪
- [ ] 码率（bitrate）与画质的关系；CBR / VBR 的概念
- [ ] I / P / B 帧与 GOP：只理解「作用与代价」，不深入算法

### 封装与容器

- [ ] MP4 / MKV / FLV / TS 各自的定位与典型场景
- [ ] MP4 moov box 的位置为什么影响点播首开（faststart）
- [ ] TS 为什么适合直播切片

### 业务形态与时延谱系

- [ ] 点播 / 直播 / 实时互动的时延量级：点播（秒~分钟级起播）、直播（3~20s，LL-HLS 可进 2s）、RTC（< 400ms）
- [ ] 音画同步问题的来源：采集、编解码、网络抖动、渲染路径不一致

### 核心指标

- [ ] 首开时间、卡顿率、时延、成功率的定义
- [ ] QoS 与 QoE 的区别与联系

## 阶段自测

1. 为什么点播网站的 MP4 要把 moov box 放在文件开头？
2. 48kHz、16bit、双声道的 PCM 一分钟占多大存储？请现场估算。
3. YUV420 相比 RGB24 大约节省多少空间？为什么视频用 YUV？
4. 直播 3~20 秒的时延主要花在哪些环节？
5. QoS 和 QoE 有什么区别？各举一个指标。
