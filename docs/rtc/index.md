# 学习路线总览

## 学习范围

本站聚焦音视频的**概念、基础理论与协议**，从浅入深：

- ✅ **学**：基础概念与理论、流媒体协议、RTC / WebRTC、QUIC 与 MoQ 等音视频传输技术
- ❌ **不学**：编解码算法与实现（H.264 / AV1 / Opus 的原理细节）——编解码只作为概念层背景出现，理解协议与架构不依赖编解码细节

## 阶段总览

时间基准：业余时间，每天 1~2 小时；总周期约 **18 周（4 个月左右）**。

| 阶段 | 主题 | 建议时长 | 累计周期 |
| --- | --- | --- | --- |
| [一](/rtc/stage-1/) | 音视频基础概念与理论 | 3 周 · 约 30 学时 | 第 1~3 周 |
| [二](/rtc/stage-2/) | 流媒体与传输协议 | 4 周 · 约 40 学时 | 第 4~7 周 |

## 各阶段简介

### 阶段一 · 音视频基础概念与理论（3 周）

建立全景认知：从采样量化到封装容器，从时延谱系到 QoS/QoE。学完后你能用一张图讲清「音视频是怎么从摄像头到屏幕的」。

→ [进入阶段一](/rtc/stage-1/)

### 阶段二 · 流媒体与传输协议（4 周）

逐个击破 RTMP / HLS / DASH / RTSP·RTP / SRT，理解直播链路的每一环，并用 FFmpeg 完成一次推拉流实践。

→ [进入阶段二](/rtc/stage-2/)

### 阶段三 · RTC 与 WebRTC 核心（5 周）

信令与 SDP、ICE / STUN / TURN、DTLS-SRTP、RTP/RTCP 与 SFU 架构——实时通信的全栈概念地图，外加浏览器 1v1 通话与 Rust 信令服务两个实践。

→ [进入阶段三](/rtc/stage-3/)

### 阶段四 · QUIC 与新一代音视频传输（4 周）

QUIC、HTTP/3、WebTransport 与 MoQ：面向未来的音视频传输协议栈。

→ [进入阶段四](/rtc/stage-4)

### 阶段五 · 综合串联与进阶视野（2 周）

全链路时延分析、QoE 指标体系、行业架构对比，输出一篇综述或一张全景图收官。

→ [进入阶段五](/rtc/stage-5)

## 如何使用本站

1. 按顺序学习，每个阶段页有**知识点清单**，学完一项勾一项。
2. 每个阶段末尾有**自测问题**，能独立回答才算过关。
3. 阶段三的两个实践务必动手做——概念只有在实践后才真正属于你。
